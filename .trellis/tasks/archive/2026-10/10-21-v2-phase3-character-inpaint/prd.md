# V3: 游戏角色工坊与画布框选批注局部重绘 — PRD

## 1. 目标

在 V1（文生图）与 V2（工作台后处理）之上，面向游戏开发中最耗时的**角色资产制作**与**局部细节返工**两大痛点，推出两大杀手级功能模块：**「角色工坊 (Character Forge)」** 与 **「工作台框选批注局部修改 (Annotated Region Edit)」**。

---

## 2. 功能设计

### 2.1 工作台：多框选批注局部修改 (Annotated Region Edit)

#### 交互流程
1. 用户在工作台切换到 **「局部批注修改 (Region Annotate)」** 工具。
2. 在画布上自由拖拽拉出 **1 个或多个矩形/多边形选框**（自动编号 `#1`、`#2`、`#3`）。
3. 每个选框旁弹出轻量备注气泡，用户输入具体修改指令：
   - 例如 `#1`（框住剑柄）：*“把剑柄改成暗金色的巨龙爪造型”*
   - 例如 `#2`（框住剑刃缺口）：*“修复缺口，加上蓝色冰霜符文发光”*
4. 点击 **「一键应用局部修改」**，生成结果以新图层/新版本呈现，支持与原图滑动对比，不满意可随时撤销。

#### 底层实现原理（双模式自动适配，确保所有 API 可用）
- **模式 A：视觉标记引导法（通用主力，支持 Gemini / GPT-4o / Nano-Banana / Seedream 等所有支持垫图的接口）**：
  1. Rust 后端在后台生成一张带有醒目编号选框（`#1`, `#2`）的视觉引导图，将原图 + 视觉引导图 + 结构化批注指令（*"Modify only the marked regions according to the instructions while keeping the rest of the image consistent: Region #1: ... Region #2: ..."*）发送给多模态生图接口。
  2. 直接采用模型返回的完整生成图（不做死板的选框像素裁剪回贴，避免新造型超出选框被截断或产生接缝错位），并在工作台支持与修改前原图一键前后对比或撤销。
- **模式 B：标准 Mask Inpainting（针对原生支持 `mask` 参数的 `/v1/images/edits` 模型如 `gpt-image-1`）**：
  - 自动根据所有选框生成透明通道 Mask PNG，连同合并后的修改指令直接调用原生局部重绘接口，直接采用模型返回的完整结果图。

### 2.2 角色工坊 (Character Forge)

专为游戏角色从“概念立绘 → 三视图设定 → 多套时装换装 → 序列帧动画”打造的一站式流水线：

#### 功能一：角色立绘与标准三视图生成 (Character & Turnaround Sheet)
- **输入**：文字描述（种族、职业、体型、服饰、配色）或上传已有的单张角色立绘参考图。
- **一键生成三视图**：内置经过调优的 **Character Turnaround Sheet 专用模板**（自动固定横版长宽比 `1536×1024`，强约束同一画布内严格左中右排列 **正面 Front / 侧面 Side / 背面 Back**，统一 T-Pose 或 A-Pose、统一头身比与纯白背景）。
- **自动切分存档**：生成三视图后，支持一键把正、侧、背三个视角切分为独立透明底单图存入角色档案。

#### 功能二：基于三视图的角色换装派生 (Outfit Variant Generator)
- **痛点解决**：游戏里同一个主角需要“新手布衣”、“铁甲套装”、“圣诞时装”等多套皮肤，普通生图每次连脸型和身高都变了。
- **实现机制**：
  1. 选定一张已有的 **角色基准三视图（或基准立绘）** 作为锁定锚点（Identity Anchor）。
  2. 输入新服装描述（如*“换上赛博朋克黑色机能风衣，带霓虹护目镜”*），或额外上传一张**服装参考图**。
  3. 后端通过多图参考协议（Reference Images + Identity-Preserving Prompt 模板：*“Strictly preserve the character's face, hairstyle, body proportions, pose, and turnaround layout from Image 1. Only replace the outfit with: ...”*）调用模型，输出保持同一角色特征的全新换装三视图/立绘。

#### 功能三：角色序列帧动画生成与切帧预览 (Sprite Sheet & Animation Previewer)
- **动作预设**：内置 `待机呼吸 (Idle)`、`4帧/6帧/8帧行走 (Walk Cycle)`、`奔跑 (Run)`、`挥砍攻击 (Attack)`、`受击/死亡` 等游戏常用动作网格模板。
- **生成与自动校准**：
  1. 以选定角色图为参考，引导模型在单张大图上按固定行列（如 `2×2`、`2×4`、`3×3`）生成连续动作网格图。
  2. **Rust 自动切帧与重心对齐 (Auto-Slice & Pivot Align)**：这是解决 AI 序列帧“抖动”的核心——Rust 自动对网格做连通域检测或按网格切分，先跑一遍 AI 抠图（或像素纯化），再**自动计算每帧角色的底部脚底中心点（Bottom-Center Pivot）并对齐到同一基准线**，消除帧与帧之间的位置漂移。
- **内置动画预览器与导出**：
  - 在界面内直接以 `4 ~ 24 FPS` 循环播放序列帧动画、支持洋葱皮（Onion Skin）叠影微调单帧偏移。
  - 支持导出：**合并的整齐 Sprite Sheet 大图 + JSON 坐标文件**、**逐帧独立 PNG 序列**、或 **动图 GIF / WebP**。

## 3. 工作流状态保活与重启持久化 (Workflow Keep-Alive & Persistence)

- **跨页签 DOM & 画布保活 (`src/App.svelte`)**：
  - `GenerateView`、`StudioView`、`CharacterView` 均常驻保活（通过 CSS 显隐切换而非销毁卸载），在页签之间任意来回切换时，画布图层、撤销/重做栈（Undo/Redo）、序列帧动画预览状态 100% 保持原样。
- **跨重启工作流草稿自动恢复 (`src/lib/stores/workspace.ts`)**：
  - 自动记住上次停留的主工作台页签（`生图工坊` / `工作台` / `角色工坊`）。
  - 自动持久化并恢复三大工坊正在编写的提示词草稿、修饰词标签、负面护栏、工作台工具参数与当前图片上的 `#1, #2` 局部批注选框、以及角色工坊的锁定基准角色与三视图/换装/序列帧参数配置。

## 4. V3.1 角色工坊模块化重构、透明可编辑模板与序列帧防出界引擎

1. **模块化注册表与状态隔离 (`src/features/character/modules.ts` & `CharacterView.svelte`)**：
   - 左侧设立独立可扩展的**「角色工坊模块中心 (`CHARACTER_MODULES`)」**，将 **「MOD-01 · 三视图与角色换肤」**、**「MOD-02 · 序列帧动画工坊」**、**「MOD-03 · 角色表情差分集」** 彻底解耦为独立模块。
   - 每个模块拥有各自独立的参考图槽位与结果画布；在序列帧模块中，底部资产胶片栏悬停时明确区分 **「设为参考图 (用于生图)」** 与 **「载入切帧 (用于切帧与预览)」**，彻底杜绝角色立绘与序列帧大图混淆。
2. **「默认模板」零污染动作预设与虚拟 Placeholder**：
   - 动作预设首位提供 **「默认模板（自由输入）」**，不注入任何内置分镜规则，100% 由用户输入的提示词主导动作；
   - 提示词输入框保持清爽空白，仅以灰色虚拟提示（Placeholder）展示示例，用户打字即消失。
3. **序列帧预览器滚轮缩放与三重防出界（Anti-Out-of-Bounds & Zero-Clip Engine，`src/lib/imaging/spritesheet.ts`）**：
   - **预览器**：支持鼠标滚轮无级缩放（`0.5× ~ 8×`）与拖拽平移检视像素细节；
   - **生图端**：支持自动生成并附带 **`Rows × Cols` 虚拟安全区网格布局引导图 (`buildSafeGridGuideDataUrl`)**，约束每帧角色与武器处在格子中心 70% 安全区内；
   - **切帧端**：采用 **8-连通域智能聚类切帧 (`extractCellsByConnectedIslands`)** + **网格框线自动擦除 (`stripGridBorderLines`)**，自动找回跨过均匀网格线的刀尖/武器末端，并自动剔除隔壁格子越界闯入当前帧角落的脚尖残片；
   - **对齐端**：采用 **全序列自适应安全画布扩容 (`preventClipping`)** + **下半身平方加权稳定质心 (`computeCharacterFootPivot`)**，对齐脚底重心后自动根据全序列最大挥刀跨度扩展安全画布尺寸，确保挥刀、突刺、高举过顶 100% 零出界、零截断。
4. **全量国际化（i18n）、无预设干扰模型池与全档位分辨率（1K / 1080P / 2K / 4K / 自定义）**：
   - 语言切换收拢至设置页可扩展下拉框（`SUPPORTED_LOCALES`），精修工作台、角色工坊、本地 AI 抠图模型名称与描述、右键菜单及 Toast 全面支持中英双语实时切换；
   - API 模型池彻底移除内置预设模型干扰，完全以用户实际拉取或手动添加的模型为准；
   - 画幅尺寸支持 1K、1080P（`1920×1080` / `1080×1920`）、2K（`2048×2048` / `2560×1440`）、4K（`3840×2160` / `4096×4096`）及自定义 `W × H`，后端具备两段式白名单自动回退与 Lanczos3 保比例精确落盘定尺。
