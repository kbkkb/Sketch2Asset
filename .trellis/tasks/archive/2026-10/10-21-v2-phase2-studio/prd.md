# V2: Pro Studio 工作台 (AI 抠图 / 像素纯化 / 批量修补) — PRD

## 1. 目标

在 V1 生图基础上，构建游戏资产后处理工作台（Pro Studio）。支持从生图结果一键送入或从外部直接批量拖入图片，在纯 Rust + 前端 Canvas 协同下完成 **GPU 深度学习抠图、物理去白边、AI 假像素网格纯化、笔刷点选精修与多规格导出**。

---

## 2. 功能范围

### 2.1 纯 Rust 原生 AI 抠图引擎 (`matting/`)
- **ONNX Runtime + DirectML 硬件加速**：无需 Python 环境，直接通过 Rust `ort` 调用显卡推理（无独立显卡自动回退 CPU）。
- **模型按需下载与管理**：内置 `BiRefNet (默认旗舰)`、`BEN2`、`BiRefNet-HRSOD`、`BiRefNet-Lite`、`ISNet-General`、`ISNet-Anime` 模型清单，首次选中时后台带进度下载至 `%APPDATA%/models/` 并校验 SHA-256。
- **专业级去白边与游戏引擎边缘保护**（完整移植并优化自 v1）：
  1. **前景物理反解 (Foreground Unmixing)**：自动估算背景色，反解半透明边缘像素的真实前景色，彻底消除白底/灰底染色。
  2. **边缘内缩 (Choke 0~3px)**：支持滑块调节 Alpha 边界内缩，消除浅色道具残边。
  3. **4px 色彩外扩 (Color Bleed)**：将边缘颜色向全透明区域外扩 4px，防止游戏引擎双线性采样产生黑边/白边。
  4. **增强补回模式 (Enhanced Recovery)**：自动找回紧贴背景但被模型误删的高饱和度细节。

### 2.2 AI 像素艺术纯化与弹性网格重绘引擎 (Pixel Art Cleaner — 100% 本地确定性算法)
- **消除 AI 伪像素的四大痛点**：针对扩散模型生成的“伪像素图”（① 单个像素块内部存在微弱渐变与色差噪点；② 网格步长不均匀、局部漂移对不齐；③ 像素交界处存在抗锯齿过渡模糊；④ 细小 `1px` 深色轮廓线易在简单降采样中丢失），采用 **纯本地四阶段几何与色彩纯化管线**（无需调用任何联网大模型）：
  1. **游程跨度直方图周期检测 (Run-Length Edge Span Histogram)**：扫描全图水平与垂直显著色跳/透明度跳变间距，通过 `3-tap` 抖动核 `[s-1, s, s+1]` + 二倍频谐波增强 + `5-tap` 亚像素质心细化，精准测算水平与垂直真实像素步长 `(stepX, stepY)`（允许 X/Y 轴存在最高 `20%` 的长宽比漂移，解决 AI 生图常见的行列拉伸不一致问题）。
  2. **一维弹性动态规划网格对齐 (1D Elastic Seam Alignment DP)**：允许每一刀切分线在理论网格步长 `[0.72*S, 1.32*S]` 范围内弹性微调，自动吸附到局部最强的色彩跳变边缘，同时通过弹簧正则项在平坦色块区维持均匀步长，彻底解决“网格对不上/局部歪斜”。
  3. **格内平坦核心采样 + `1px` 深色轮廓线保护 (Flat-Interior Cluster + Dark Outline Guard)**：剔除每个网格四周 `12%` 的抗锯齿交界区并按内部梯度反比加权；若格内存在占比 $\ge 22\%$ 且与主色亮度差 $> 65$ 的深色轮廓簇，自动激活轮廓保护，确保眼睛、耳朵、尾巴等连续 `1px` 描边绝不因背景膨胀而断裂。
  4. **感知色差两阶段收拢 + 规整正交网格重绘 (Perceptual Color Coalescing + Uniform Rectified Redraw)**：内置“色差收拢净化 (`coalesceTolerance`, 默认 `22`)”滑块，自动将同一色系下的上百种 AI 杂色/微弱阴影吸收合并为纯粹平色（同时保护高对比特征色与暖白/纯白区分），剔除孤立单格杂色后，将非均匀的弹性采样格重绘到严格均匀的正交像素网格（支持实时开启 `显示网格线` 检视，以及保留原图供 `对比原图` 按住检视）。
- **双重导出**：支持导出保持原图高分辨率的锐利正交像素图，或一键导出 **真实 `1:1` 原生低分辨率（如 `62×58`、`64×64`）真像素 PNG**。
- **生图联动**：在 V1 生图界面选择“像素风”时，可勾选“生成后自动执行像素纯化”。

### 2.3 交互式画布修补与批量工作流
- **高频画布工具栏**：平移缩放（空格/中键）、按颜色连通域点选恢复/擦除（带色彩容差滑块）、自由笔刷涂抹恢复/擦除（带笔刷半径预览）、框选裁剪、一键自动裁切四周透明边（Auto-Trim）。
- **多步撤销/重做栈**：支持 `Ctrl+Z` / `Ctrl+Y` 历史回退。
- **系统级拖拽批量导入**：支持从 Windows 资源管理器直接拖入单张或多张外部图片到工作台视口，自动批量导入当前项目并可一键排队批量抠图/纯化。
- **自定义分辨率无损导出**：指定宽高、保持纵横比居中填充导出透明 PNG。
