# V1: 桌面端基础框架与核心文生图 — PRD

## 1. 目标

完成 Sketch2Asset v2 的第一版可独立运行桌面客户端，实现“配置 API → 选择/搜索模型 → 输入提示词（可选垫图）→ 并发生成 → 自动归档至项目图库”的完整高效闭环，彻底解决 v1 端口断连、配置丢失、模型下拉框狭窄难用等痛点。

---

## 2. 功能范围与设计决策

### 2.1 桌面外壳与全局基础 (App Shell)
- **无边框自定义标题栏**：集成应用 Logo、主视图切换（`生图 Generate` / `工作台 Studio [V2解锁]` / `角色工坊 Character [V3解锁]` / `设置 Settings`）、当前活动 API 方案与模型状态胶囊、中英语言切换、深浅主题切换、窗口最小化/最大化/关闭按钮。
- **响应式底线**：最小窗口 `1100 × 700`，任何缩放下表单与下拉框绝不挤压变形。

### 2.2 API 方案管理与安全持久化 (Provider Profiles)
- **多配置方案切换**：支持创建、重命名、删除多个 API 方案（如“官方 OpenAI”、“中转站 A · Gemini”、“中转站 B · Seedream”）。
- **双通道永久存储**：
  - 方案元数据（名称、Base URL、接口类型 `images` / `chat`、默认模型、已拉取的模型列表）保存在 `%APPDATA%/com.sketch2asset.app/settings.json`。
  - `API Key` 通过 Rust `keyring` 存入 **Windows 凭据管理器**，前端只读取 `hasKey: boolean` 状态，彻底杜绝明文泄露与升级丢失。
- **配置导入/导出**：兼容 v1 导出的配置 JSON，支持一键迁移旧版配置。

### 2.3 IDE 级模型可搜索下拉框 (Model Combobox)
- **一键在线拉取**：通过 Rust `reqwest` 调用上游 `GET /v1/models`，自动解析并按 `✨ 图像与多模态模型 (带 IMAGE 徽标)` 与 `⚡ 全部模型` 分组。
- **即输即搜 + 随时展开**：点击即展开完整列表（无需先清空输入框），顶部独立搜索框支持模糊过滤，支持键盘上下键与 `Enter` 任意自定义模型名。
- **生图顶栏直达**：在生图主界面直接放置宽幅方案切换与模型 Combobox，无需频繁切去设置页。

### 2.4 高效文生图工作流 (Core Generation)
- **结构化提示词组装**：
  - **主体输入框**：底部悬浮指令舱（Command Dock），支持 `Ctrl + Enter` 极速提交。
  - **游戏素材品类芯片 (Archetype Chips)**：`默认自由`、`道具图标`、`像素精灵`、`场景贴图`、`UI 元素`。选中后自动在底层拼接最佳构图/边缘提示词后缀。
  - **美术风格与背景控制**：内置像素风、美式卡通、二次元、3D 渲染、低多边形、写实、水彩等风格预设；背景默认锁定**摄影棚纯白底**（可选中性灰/纯黑/不指定）。
  - **分辨率与单次张数**：支持 `自动`、`1024×1024`、`1536×1024`、`1024×1536` 及自定义宽高；支持单次并发张数 `×1 / ×2 / ×4`。
- **草图/参考图引导**：支持点击选择、文件拖入、`Ctrl + V` 剪贴板直接粘贴图片作为生成引导。
- **双协议引擎 (`providers/`)**：
  - `OpenAI Images 模式`：无参考图走 `/v1/images/generations`，有参考图走 `/v1/images/edits` (multipart)，失败自动降级重试。
  - `OpenAI Chat 模式`：走 `/v1/chat/completions`，自动解析 Markdown 图片链接、`data:image/...` Base64 以及多模态块返回。

### 2.5 时间线画廊流与项目归档 (Timeline Stream & Project Hub)
- **非阻塞后台任务**：点击生成后立即创建任务卡片（展示实时读秒与 Stage 流体动效），输入框不锁死，可连续提交下一批生成任务。
- **项目隔离归档**：支持新建、重命名、切换项目，每个项目可独立锁定专属画风后缀；生成的原图落地为本地 PNG，元数据（Prompt、模型、耗时、种子/参数）写入 SQLite 索引与同目录 JSON。
- **结果快捷操作**：预览大图、一键打开所在文件夹、复制图片到剪贴板、另存导出 PNG。

## 3. 验收标准 (Acceptance Criteria)

- [x] 启动桌面端应用，添加 API 方案并填入 Key，重启应用后配置与 Key 100% 保持。
- [x] 点击「拉取模型」能正确从兼容 API 获取模型列表，Combobox 展开、搜索、分组徽标与任意宽度显示正常。
- [x] 在 `images` 和 `chat` 两种接口模式下，纯文本生图与带草图生图均能成功落盘并显示在时间线画廊中。
- [x] 支持一键导入 v1 的配置 JSON。
- [x] 中英双语切换、深浅主题切换无任何硬编码遗漏，UI 零 Emoji。
